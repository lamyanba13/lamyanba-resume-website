# Lamyanba Sadokpam Resume Website

A polished static resume website built from Lamyanba Sadokpam's professional profile, experience, projects, education, tools, certifications, and role targets.

## Open Locally

Open `index.html` in a browser. No build step or dependency installation is required.

## Files

- `index.html` - Resume website markup and content
- `styles.css` - Responsive visual design and print styles
- `script.js` - Print, copy email, and active navigation behavior
